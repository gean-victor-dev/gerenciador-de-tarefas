# gerenciador-de-tarefas
Aplicação web simples de gerenciamento de tarefas desenvolvida com HTML, CSS e JavaScript puro, contando com persistência de dados via `localStorage`.

## Funcionalidades
- Adicionar novas tarefas.
- Marcar tarefas como concluídas ou pendentes.
- Excluir tarefas.
- Filtrar tarefas (Todas, Pendentes, Concluídas).
- Salvar dados no navegador (`localStorage`).

## Tecnologias Utilizadas
- HTML5
- CSS3
- JavaScript 

## Como executar
Basta clonar o repositório e abrir o arquivo `index.html` em qualquer navegador web.
